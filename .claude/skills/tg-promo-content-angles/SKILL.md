# ThrottleGuard Content Angles

Generate hooks that come from the product's real technical substance and the founder's field credibility — not generic SaaS marketing filler.

## Angle categories to draw from

**1. Technician credibility angles**
- "20 years pulling DPFs taught me X" style posts — specific, textured field knowledge (ash vs. soot backpressure, EGT channeling, regen requesting at lower temps over time = degrading DPF).
- Myth-busting: "Your dealer's scan tool doesn't see this" / common misdiagnoses.

**2. Cost-of-failure angles**
- What an EPA derate roadside call actually costs a fleet in downtime + towing + repair.
- DPF replacement cost vs. catching clogging early.
- Detroit 1-Box specific: one thermal event damages DPF *and* SCR simultaneously — bigger bill, bigger angle.

**3. "Here's exactly how it works" transparency angles**
- Walk through one rule (e.g., Rule 3: sensor delta fault, Rule 11: NOx conversion <50%) as a mini case study — this plays well because it proves it's not a black box.
- Before/after: raw sensor readings → the rule that fires → the plain-English action a tech takes.

**4. Duty-cycle / operational angles**
- Short-haul + excessive idle + poor fuel = fastest DPF clogging combination — useful for local delivery / drayage fleet audiences specifically.
- Engine-family nuance: why a Cummins/PACCAR threshold shouldn't be applied to a Detroit truck.

**5. Product/business angles**
- 14-day trial, no card — remove-the-friction post.
- Standalone-first: "you don't need to rip out your telematics stack" for fleets nervous about vendor lock-in.

## What NOT to do

- Never generate content claiming ML/AI/predictive modeling — the engine is rule-based; say so plainly if the angle touches on "how it works."
- Don't fabricate specific customer results, testimonials, or dollar figures — use industry-typical framing or ask the user for a real data point to cite.
- Don't overuse the founder-story angle to the point of one-note; rotate across all 5 categories in a content calendar.

## How to run this skill

1. Ask (or infer) the channel — LinkedIn (professional, story-driven), trucking forums/Facebook groups (peer-to-peer, blunt, no corporate tone), email newsletter (educational, longer-form), trade show one-pager (visual, scannable).
2. Produce a batch (default 10, ask if the user wants more/fewer) of angle + hook headline pairs, tagged by category above, mixing categories rather than clustering.
3. For any angle the user picks to develop further, expand it into a full draft — hand off to a general content draft, keeping the technical facts accurate to CLAUDE.md (rule numbers, thresholds, engine families) rather than approximating.
